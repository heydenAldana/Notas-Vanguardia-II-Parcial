3. Los grupos que hcieorn +40 dispositivas, hay un lugar muy especial para ellos :)
4. Los ejemplos de código **NO VIENEN INCLUIDOS**
5. El contenido se basa EXCLUSIVAMENTE en las diapositivas que fueron compartidas. Uds háganse responsables de verificar la autenticidad de la información
